Supplementary Data for 'Discrete or graded? A confound-controlled re-analysis of clustering in Egyptian fruit bat social calls'.
All files are derived from the analysis scripts' result files without recomputation (script 50).
SD1  all 1,558 clustering configurations: algorithm family, parameter, representation, number of clusters, noise share, silhouette, NMI with channel/silence, Isolation precision/recall/F1, run time.
SD2  the best admissible configuration (at least two clusters holding >= 1% of points, highest silhouette) per algorithm and representation, with bat-transfer ARI.
SD3  detection rates of the one-cluster-allowed battery for spiked two-type mixtures, with 95% Wilson intervals.
SD4  observed value, null mean, null 2.5th/97.5th percentiles and empirical counts (null replicates >= observed) of each clusterability statistic, per representation.
SD5  Isolation AUC with bat-level bootstrap intervals, sample sizes and bats by pup-age window, held-out channel and held-out treatment.
SD6a/b  data partitions (files, Isolation files, bats, channels, days) and the overlap of held-out bats, channels and days with the discovery sample.
SD7  Python package versions of the analysis environment.
